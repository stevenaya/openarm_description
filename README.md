# OpenArm PR review images

RViz screenshots referenced from pull-request descriptions in [enactic/openarm_description](https://github.com/enactic/openarm_description).

The `comparisons/2026-10-22` images compare PRs #98, #99, #100 and #101 against their common base. Each before/after pair was captured in a separate RViz scene with identical model placement, camera settings and viewport dimensions. The #99 inertia boxes use the native RViz RobotModel inertia display. The #100 arrows use the CAD camera reference frame.

Source commits and capture validation accompany the images. This branch stores review images independently of the model PR branches.
